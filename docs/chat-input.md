# 在 Minecraft 里打中文，怎么最省事

Minecraft 的中文输入痛点只有一个：**独占全屏把所有输入法候选框都挡在外面**。
Windows 的微软拼音、搜狗、微信输入法都是靠一个浮动窗口显示候选字的，
而独占全屏的那块画面归游戏独占，候选框画不出来，于是你只能盲打。

下面三条，按省事程度从高到低。

---

## 一、最省事：干脆不在游戏里打字

用 `tools/chat-in.bat`。

双击，屏幕上方会浮出一个常驻小窗。在里面打中文，按回车，这句话就直接发进
游戏聊天框了——像你自己敲的一样。窗口一直置顶，边玩边用，不用切输入法、
不用切窗口、不用离开游戏。

- 走本机桥 `http://127.0.0.1:8790/chat`，只连 127.0.0.1，不出网；
- 需要游戏正在运行，并且装着 `dist/` 里的那个 Forge 桥 mod；
- `上`/`下` 翻你刚说过的话，`Esc` 清空，`Ctrl+H` 收起窗口；
- 以 `/` 开头就当成命令发（例如 `/gamemode creative`）。

想更省事，右键这个 bat → 发送到 → 桌面快捷方式，再给它设个快捷键，
以后一个组合键就能调出来。

## 二、动嘴：语音输入

同伴本身就带耳朵。游戏里按语音键说话，Vosk 认中文，认出来的文字能直接送进
聊天，也能直接当指令给她。模型怎么装见 `docs/local-models.md`。
打字的活儿，能开口就开口。

## 三、还是要手打：让候选框能显示出来

把游戏从「独占全屏」改成「窗口」或「无边框窗口」：

1. 游戏里 `Esc` → 选项 → 显示设置 → **全屏：关**；
2. 或者直接改 `options.txt`，把 `fullscreen:true` 改成 `fullscreen:false`；
3. 窗口模式下，输入法候选框就会正常浮在游戏画面上面，盲打问题消失。

如果不想改窗口，还有两个偏方：

- 用 Windows 自带的**微软拼音**，并在「设置 → 时间和语言 → 语言 → 中文 →
  选项 → 微软拼音 → 常规」里打开「**兼容性**」（旧版候选窗在独占全屏下
  更容易冒出来）；
- 换一个支持「全屏注入」的输入法，或者把游戏的分辨率调成窗口大小后
  用「无边框窗口」工具（例如 Borderless Gaming）铺满屏幕——视觉上还是全屏，
  但技术上已经是窗口了，候选框能出来。

---

## 小结

| 你想要 | 用哪个 |
| --- | --- |
| 完全不想切输入法 | `tools/chat-in.bat` |
| 手离键盘 | 语音键 + Vosk |
| 就在游戏里手打 | 游戏改窗口模式 |
